# WuNa - Encrypted Chat App (Local Network)

WuNa is a simple, encrypted chat application that allows users to communicate securely over a local network. All messages are encrypted using the Fernet symmetric encryption scheme from the `cryptography` library.

## Features

-   **End-to-End Encryption:** All messages are encrypted and decrypted on the client-side.
-   **Multi-User Chat:** Supports multiple clients connected to a central server.
-   **Simple Setup:** Easy to get started with just a few commands.

## Requirements

-   Python 3.6+
-   `cryptography` library

## How to Use

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/wuna.git
    cd wuna
    ```

2.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Generate a secret key:**
    A secret key is required for encryption. The first time you run the server, it will automatically generate a `secret.key` file. This key must be shared with all clients who wish to join the chat.

4.  **Run the server:**
    ```bash
    python server.py
    ```
    The server will start listening for incoming connections.

5.  **Run the client:**
    Open a new terminal and run the following command:
    ```bash
    python client.py
    ```
    You will be prompted to enter a username. After that, you can start sending and receiving messages.

    **Note:** Ensure that the `secret.key` file generated by the server is present in the same directory as the client script.

## How it Works

-   **Server:** The server (`server.py`) is responsible for accepting client connections and broadcasting messages to all connected clients. It does not see the content of the messages, as they are encrypted.
-   **Client:** The client (`client.py`) connects to the server. It encrypts messages before sending them and decrypts messages upon receiving them.
-   **Cryptography:** The `crypto.py` script handles the encryption and decryption logic using the `cryptography` library. It uses a symmetric key, so the same key is used for both encryption and decryption.

## Disclaimer

This is a simple application for educational purposes and may not be suitable for environments that require high security.
